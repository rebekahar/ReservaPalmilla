# Reserva at Villas del Mar, Palmilla

Static website — no build step.

- `index.html` — home page
- `gallery.html` — gallery
- `assets/gallery/` — gallery photos (keep this folder next to the HTML files)

## Publish on GitHub Pages
1. Upload everything in this folder to the root of a GitHub repository.
2. Repository → Settings → Pages → Source: "Deploy from a branch", Branch: `main`, folder `/ (root)`.
3. Optional: add your domain (reservapalmilla.com) under Custom domain.

## Newsletter
Sign-ups are emailed to rebekah@iriscapital.mx via FormSubmit. The first sign-up sends an activation email to that inbox — click the link once to start receiving submissions.
